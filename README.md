# Ali Ostowar

Dual MSc student at Utrecht University (Artificial Intelligence + Neuroscience & Cognition).

I work on **AI evaluations**, especially on how methods from cognitive neuroscience
and psychometrics can help measure properties of models that are hard to observe directly.
Consciousness is my hardest test case: what evidence could actually tell us whether
a system, animal or AI, has experiences?

### Projects
- **[power_seeking](https://github.com/AlijaY69/power_seeking)**: evaluating power-seeking
  tendencies in LLMs with [Inspect](https://inspect.aisi.org.uk/), built on ARENA's evals chapter.

### Research
- *Triangulating Phenomenal Consciousness: An Eliminative-Iterative Method for Escaping
  Anthropocentric Indicators* (with Dr. Schutter), in preparation. Audits Butlin et al.'s (2023)
  consciousness indicators, using rats as an anchor case.
